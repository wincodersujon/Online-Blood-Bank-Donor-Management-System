How to run the Online Blood Bank & Donor Management System Using PHP and MySQL

1. Download the zip file from https://topsourcecode.com/

2. Extract the file and copy obbdms folder

3.Paste inside root directory(for xampp xampp/htdocs, for wamp wamp/www etc)

4.Open PHPMyAdmin (http://localhost/phpmyadmin)

5. Create a obbdms with the name obbdms

6. Import obbdms.sql file(given inside the zip package in the SQL file folder)

7. Run the script http://localhost/obbdms or terminal: php -S localhost:8000
